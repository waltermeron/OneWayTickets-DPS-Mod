# 再再启程 DPS 可视化 Mod v1.0.3

正式整合版，适配游戏 v0.8.0.2。安装后解压至游戏根目录，之后正常启动游戏即可。不影响成就解锁

## 更新历史
v1.0.1: 新增车速显示

v1.0.2: 新增实际车速单位，与游戏内距离单位、数值一致

v1.0.3:优化爆炸箭袋等辅助装备与被辅助武器之间的伤害显示：通过F6，切换伤害合并或者分离； 优化奇物增益显示
## 武器统计

- 读取游戏的本地化武器名、品质等级、原始图标；名称使用对应品质色。品质色从游戏品质条贴图的主色读取，并提高亮度以适应深色面板；无法读取时使用备用品质色。
- 每把武器显示近 5 秒实时 DPS、全局 DPS、累计有效伤害和占全部有效伤害的百分比，附占比条。
- 同名武器按独立实例分行，保留装备位置文字，不显示编号。默认按总伤排序，可点击右上角按钮依次切换累计伤害、实时 DPS、全局 DPS 排序。
- 轮子未造成伤害时隐藏，造成有效伤害后显示；其他已装备武器照常显示零值。造成伤害后卸下的武器会保留本次统计。
- 投射物沿 emitter 链归属武器，附着物沿 source 链归属武器。无法归属到具体武器的玩家伤害归入“其他伤害”，保证分项总伤等于总伤。

## 图表与操作

| 操作 | 功能 |
|---|---|
| F1 | 循环切换武器明细 / 实时 DPS 折线图 / 奇物增益统计，同时退出仅 DPS 模式 |
| F3 | 显示 / 隐藏整个面板 |
| F4 | 清空总计、武器统计和历史曲线 |
| F2 | 图表时间范围 60 → 120 → 30 秒循环 |
| F5 | 切换仅 DPS / 完整窗口 |
| F6 | 切换辅助伤害合并或者分离 |
| 拖动面板顶部 | 移动面板 |
| 拖动右下角斜线手柄 | 分别调整窗口宽度和高度 |
| 点击武器名称区域 | 图表聚焦该武器，同时保留总 DPS 参考线 |
| 点击图例中的武器 | 聚焦对应武器 |
| 点击图表右上按钮 | 恢复总计 + 全部有伤害来源 |
| 鼠标移入曲线区 | 查看最近采样点的时间与 DPS |

按键提示仅保留在完整面板左下角。仅 DPS 模式保留标题及实时 DPS、全局 DPS、累计伤害、平均 DPS 四项指标，退出后恢复完整窗口高度。图表展示总 DPS 和全部有伤害的来源（含其他伤害），不设前五限制；图例支持滚动。单武器视图标题、图例及采样提示均显示实际名称。

图表纵轴为 DPS，横轴为游戏统计时间（秒），纵轴自动缩放。每 0.25 秒采样一次，保留约 120 秒历史；切换显示范围不会清空历史。暂停、安全区和结算期间时间及曲线冻结。

实时 DPS 固定为最近 5 秒有效伤害之和 ÷ 5；起始不足 5 秒也除以 5。**全局 DPS 从首次有效伤害起算，平均 DPS 从进入战斗/清零起算**；两者最小时间分母均为 1 秒，均不计暂停、安全区和结算时间。每把武器的全局 DPS 使用全队首次有效伤害起算的共同分母，可相加得到总全局 DPS。进入新的局内场景或清零后重新统计。

## 窗口设置

窗口右下角提供斜线拖拽手柄，可分别调宽、调高，宽高比例可自由变化；左上角保持原位。默认尺寸为 760×668，完整窗口最小尺寸为 428×400（逻辑 UI 单位，按屏幕基准比例显示），最大尺寸受当前屏幕边界约束。缩至小窗口时内容等比缩小以保持排版，表格、曲线和说明区域随窗口宽高调整，内容较多时可以滚动。仅 DPS 模式的显示高度随宽度适配，保存的完整窗口高度继续保留。

点击右上角“窗口设置”，可调背景透明度（0%–80%，越高越透明；文字和图标保持清晰），也可恢复默认外观。“自动适配屏幕”会将面板移至左上留白处，并选取当前屏幕可容纳的宽高。拖动标题栏可移动面板，触及底边后可直接向上拖离。透明度、宽高、位置和排序会保存至 DPSMod/settings.json，下次启动继续使用；开发版尺寸会自动迁移。

源码 src/HudPreferences.cs 的定位说明注释保留同名信息。更新细节见 [更新日志.txt](更新日志.txt) 或 [CHANGELOG.md](CHANGELOG.md)。

## 奇物增益统计

F1 切换至“奇物增益统计”，读取当前拥有奇物的快照，分组展示已确认可直接累计的静态数值及其来源。条件触发和数值尚未确认的效果单独保留在已拥有奇物说明中。这里显示的是可证明的静态增益整理，战斗中的最终效果仍取决于对应条件及游戏计算。

已核对通用、近战、远程、车轮冲撞、耐久防御、能量、掉落、爆炸、飞镖、闪电等类别；可加算的同类配置值汇总并标注来源，独立触发概率不强行相加。与游戏文本统一使用“防御与耐久”“装置耐久加成”和“动力”。尚无法确认单位的参数明确标为“配置值”，特殊效果保留游戏本地化说明。

击退、近战击退和远程击退按千分制比例展示，例如原始增量 150 显示为 +15%，逐件奇物说明采用相同规则；这是奇物增量的展示规则，不代表游戏最终击退效果。

## 伤害口径诊断

有效伤害继续使用原 Mod 的口径：玩家来源对敌对目标造成的实际生命值下降，不包含治疗、未命中、免疫、己方受伤和溢出伤害；无法确认玩家来源的环境伤害不计入。直接修改生命值且绕过 ITarget.hurt 的特殊机制不计入。

游戏弹出的伤害数字和内置伤害统计可包含溢出伤害。例如目标剩余 40 生命、一次上报伤害为 300 时，本 Mod 的有效伤害记为 40，溢出部分为 260。武器明细底部提供“飘字累计”“有效累计”及“差额（含溢出）”，位于“点击武器查看单独曲线”说明上方，相隔约一至两行；对照数据与说明文字均使用更大的字体。DPS 与伤害占比继续使用有效伤害。

已修复玩家持续伤害漏记：游戏中的附着物自身阵营为中立，现在沿原攻击者链判断玩家归属，因此玩家造成的燃烧、酸液等附着伤害可以纳入；敌方、无来源附着和敌方反射后的弹丸仍排除。

## 解压包使用

根目录压缩包为直接覆盖版：退出游戏，把压缩包内的内容解压到与“再再启程.exe”同级的游戏根目录，允许覆盖文件，然后正常启动游戏。不要再套一层文件夹。

压缩包仅适用于标明的游戏版本及本目录对应的原始 World.dll，包含：
- 再再启程_Data/Managed/World.dll（已挂接统计）
- 再再启程_Data/Managed/OneWayDps.dll（统计与界面）
- DPSMod 下的原始程序集备份、卸载脚本、校验信息及说明。

压缩包不包含个人存档，也不需要 BepInEx、Harmony 或额外启动器。

卸载：退出游戏后双击 DPSMod/Uninstall.cmd，校验后恢复原始 World.dll 并移除 OneWayDps.dll。请保留 DPSMod/backup/World.dll 和 installed.json。

Steam 更新或验证完整性可能覆盖 Mod。更新后不要用旧压缩包覆盖新版本游戏，需重新适配。

## 本地开发文件

src/ 保存完整 Mod 源码；Build.ps1 重新编译；Test.ps1 运行统计与归属测试。tools/cecil 使用来自 NuGet 的 Mono.Cecil 0.11.6（MIT），元数据见 Mono.Cecil.nuspec。打包的运行版不依赖 Mono.Cecil。

原伤害函数仍执行一次并返回原结果；只添加旁路统计，不修改伤害计算。Mod 不读写游戏存档；仅将界面偏好写入 DPSMod/settings.json。
